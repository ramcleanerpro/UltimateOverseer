# ⚡ Ultimate Overseer

**Удалённое управление ПК с телефона. Бесплатно. Без облака. Без посредников.**

[![Version](https://img.shields.io/badge/version-7.5-blue)]()

---

## 🔥 Возможности

- 📺 **Трансляция экрана 30 FPS**
- 🖥 **Удалённый рабочий стол (RDP)**
- 🖱 **Управление мышью с телефона** (тачпад)
- 📁 **Файловый менеджер** (просмотр, чтение файлов)
- 🎵 **Медиа-клавиши** (громкость, плей/пауза, треки)
- ⏲️ **Таймер выключения** (15/30/60/120 мин)
- 💿 **Мониторинг дисков** (свободное место)
- 🌐 **Скорость сети** (входящий/исходящий трафик)
- ⚙️ **Управление службами Windows**
- 🔒 **Работа на заблокированном ПК** (Win+L)
- 🚀 **Автозагрузка с Windows** (опционально)
- 📱 **QR-код при запуске**

---

## 📥 Установка

### На ПК (Windows)

1. Скачай `UltimateOverseer.exe` из [Releases](https://github.com/ramcleanerpro/UltimateOverseer/releases)
2. Запусти `.exe`
3. Введи ключ: `@awall_paster`
4. Выбери порт
5. Отсканируй QR-код или введи адрес в браузере телефона

### На телефоне

- **Через браузер:** открой `http://IP_ПК:ПОРТ`
